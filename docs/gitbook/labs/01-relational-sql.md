## Getting ready

The lesson and browser activities can be explored immediately. To run the SQL practice, open the [student repository](https://github.com/OrPerets/postgres-data-engineering-student) in GitHub Codespaces and run `make lab-sql` from the repository root. No local Docker installation is required.

New to Codespaces? Follow the illustrated [first SQL lab walkthrough](../start-lab01.md), or open [Tutorial & practice](01-tutorial-practice.md) for setup, workspace and saving instructions.
