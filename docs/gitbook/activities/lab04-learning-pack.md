# Lab 04 — MapReduce practice

Use these activities before or during [Lab 04](../labs/04-mapreduce.md). They are optional practice, separate from the assignment.

## Trace Map → Shuffle → Reduce

Enter a few short records and step through a character-count trace. Try the combiner and compare the number of intermediate pairs. Each input line represents one mapper's local group for this demonstration.
